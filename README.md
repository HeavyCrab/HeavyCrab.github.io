# HeavyCrab.github.io

Personal homepage of Jianing Ye — https://heavycrab.github.io

A single static page (`index.html` + `style.css`), served by GitHub Pages as-is (`.nojekyll`). To add a paper, copy one `<li>` in the publications list. The CV source lives in `files/CV/`; recompile `CV.tex` there and commit the new `CV.pdf`.
